## 获取资料

### 在线阅读

直接点击上方书目中的链接，GitHub 会打开对应 PDF 的预览页面

### 克隆仓库

```bash
git clone https://github.com/CCU-Robotics-Association/CRA-Free-eBooks.git
cd CRA-Free-eBooks
```

克隆完成后，即可离线查看仓库中的全部资料
